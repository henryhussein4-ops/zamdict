# Contributing to ZamDict

Thanks for helping improve a beta project focused on Zambian languages. Testing reports, careful language corrections, accessibility suggestions, and code contributions are welcome.

## Before you contribute

- Check existing issues before opening a duplicate.
- Keep reports respectful and specific. Language can vary by region and context; include that context rather than presenting one variant as universally correct.
- Do not commit API keys, passwords, private contact details, or other secrets. Never put credentials in an issue, screenshot, commit, or pull request.
- Do not add personal data or community-submitted content unless you have permission to share it.
- A project license has not yet been selected. Until the owner adds one, ask before reusing or redistributing code or data.

## Report a bug or suggest a change

Open an issue with a concise title and include, when relevant:

- what you tried and what happened;
- what you expected to happen;
- the language/word/phrase and relevant regional or usage context;
- your browser, device, and whether you were online or offline;
- screenshots only if they contain no personal information or credentials.

For a language correction, include a suggested correction and an explanation or reliable source when possible. Please identify uncertainty and regional variation.

## Pull requests

Keep each change focused, explain why it helps, and test it in a modern mobile and desktop browser where practical. Since this is currently a single-file app, review changes carefully and avoid unrelated formatting churn. Include a short manual test checklist in the pull request description.

## Beta expectations

The app and its backend are under active improvement. Maintainers may ask for clarification, defer changes, or revise an implementation as the beta evolves. Please do not rely on the app as an authoritative source until content and services have been reviewed.
